Hold **Mouse4** and click your attack binding while holding a NewFirearms gun in each hand to fire both. The modifier is rebindable under Settings → Input as **Fire both guns (hold)**. Without the modifier or a second gun, the active hand fires normally. Gun-minigame pointer handling and other game menus retain their usual input rules.

Each gun uses its own safety, ammunition, charge, cooldown, jams and firing mode. Holding attack continues both automatic weapons while the modifier remains held. Releasing the modifier stops the offhand automatic weapon; the selected gun continues normally while attack is held. Releasing attack stops both. An already-started three-round burst still completes unless that gun is dropped or interrupted.

The normal attack path simply calls `Shoot` on the selected gun and, with the modifier held, the other hand's gun. In multiplayer both calls use the ordinary shoot action. The host verifies that each requested gun is held by the requesting body. Ordered gun input messages ensure release cannot overtake the firing request. Shot effects and ammunition/charge changes use the existing synchronization paths. No optional multiplayer assembly is required for singleplayer.
